## Project Description
This project is a React/Next.js notification application developed for the AffordMed Campus Hiring Evaluation.
### Features
- Display all notifications
- Priority notifications
- Filter by notification type
- Read/Unread distinction
- Responsive UI
## Run Locally
```bash
npm install
npm run dev
```
Open http://localhost:3000
